# 🎙️ Voice Reminder – Piper TTS Edition

Versión personalizada del plugin Voice Reminder para Super Productivity, con integración de síntesis de voz local mediante Piper TTS.

## ✨ Características

- Síntesis de voz local mediante Piper TTS.
- Personalización de voces e idiomas.
- Recordatorios por voz personalizados.
- Reproducción aleatoria de mensajes.
- Recordatorios de descanso configurables.
- Mejoras y funcionalidades adaptadas a mis preferencias.

## 🚀 Sobre el proyecto

Proyecto personal desarrollado de forma iterativa con ayuda de OpenAI Codex.

El objetivo es adaptar Voice Reminder a mi flujo de trabajo, experimentar con nuevas funcionalidades y mejorar progresivamente la experiencia de uso.

## 📦 Descargas

En este repositorio encontrarás los archivos ZIP de las versiones disponibles:

- Código fuente del proyecto.
- Versión empaquetada 2.0.0.

## ⚙️ Requisitos

- Super Productivity.
- Piper TTS.
- Modelos de voz compatibles con Piper.
